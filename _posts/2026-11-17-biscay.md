## Key Idea

Traditional congestion control algorithms work poorly with wireless cell networks.
Additionally, smartphones provide limited KPIs for the CCAs to work with. The paper
introduces a new CCA called BISCAY, which enables real time radio KPI extraction and
better congestion control on mobile phones.

## Critique

The approach seems to be effective, but more work needs to be done if it's to be widely
adopted. Software and hardware support need to be improved, namely the algorithm only
works on Qualcomm hardware.
